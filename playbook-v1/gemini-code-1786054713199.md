# 03-Patterns / CQRS (Command Query Responsibility Segregation)

---

## 1. Propósito

Separar las operaciones de lectura (Queries) de las de escritura (Commands) para optimizar performance, escalabilidad y mantenibilidad.

---

## 2. Diagrama de Arquitectura (Mermaid)

```mermaid
graph TD
    Client[HTTP Request] --> Controller[API Controller]
    Controller -->|Send Command| CmdHandler[CreateOrderCommandHandler]
    Controller -->|Send Query| QryHandler[GetOrderByIdQueryHandler]
    
    CmdHandler -->|EF Core / Write| WriteDB[(SQL Server DB)]
    QryHandler -->|Dapper / Read| ReadDB[(Read Replica / Views)]
